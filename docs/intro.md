# 📚 Documentação do New Empire

Bem-vindo à base de conhecimento do **New Empire**. Aqui estão os recursos e guias dos mods para quem joga, constrói ou administra o servidor.

## Modpack de referência

| Informação | Valor |
| --- | --- |
| Exportação analisada | **NewEmpire 1.0.0** |
| Minecraft Java | **26.3** |
| Carregador | **Fabric Loader 0.20.1** |
| Mods no manifesto | **64** |
| Fonte | Arquivo `NewEmpire 1.0.0.mrpack` fornecido para documentação, em 30/10/2026 |

> **Importante:** estes dados descrevem o arquivo distribuído. A lista e as versões em execução no servidor podem ser diferentes, já que o `.mrpack` não contém sua configuração ativa.

## Por onde começar?

1. [Instalação e primeiros passos](/docs/basico/primeiros-passos): entenda como importar o pacote e se conectar.
2. [Comandos e atalhos](/docs/basico/comandos): referência rápida para teletransporte, inventário e conteúdo visual.
3. [Catálogo dos 64 mods](/docs/explicacao-mods/catalogo): veja o que cada mod adiciona e a versão incluída.
4. [Armazenamento e interface](/docs/explicacao-mods/armazenamento), [sobrevivência](/docs/explicacao-mods/sobrevivencia) e [construção](/docs/explicacao-mods/construcao): descubra os recursos que afetam a jogabilidade.

### Guias detalhados

- [Camera Obscura](/docs/explicacao-mods/cameraobscura) para fotografias e gravações.
- [Image2Map](/docs/explicacao-mods/image2map) para quadros e painéis com imagens.
- [Patbox's Brewery](/docs/explicacao-mods/cervejaria) para preparar bebidas.

Quem administra o servidor deve consultar a [auditoria técnica e de compatibilidade](/docs/administracao/compatibilidade).

**Histórico:** as notícias antigas do blog registram versões anteriores e não representam o estado atual do modpack.
