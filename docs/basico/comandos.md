# ⌨️ Comandos e atalhos úteis

Os comandos abaixo foram verificados nas páginas dos projetos dos mods presentes na exportação. **A existência do mod no pacote não garante que seu comando esteja liberado para todos os jogadores**: permissões e configurações dependem do servidor.

| Ação | Comando / interação | Observação |
| --- | --- | --- |
| Pedir teletransporte | `/trigger TPA` | Abre uma seleção de jogadores; o destinatário deve aceitar |
| Organizar inventário | `/invsort sort` ou `/invsort sortme` | Inventory Sorting; conforme contexto e permissões |
| Ver receitas | Interface de JEI ou Polydex | JEI depende de interface no cliente; Polydex pode usar menus no servidor |
| Criar imagem em mapa | `/image2map preview <URL>` | A função pode ser limitada a certos jogadores |
| Tirar foto em mapa | `/camera-obscura` | Permissão configurável; veja o guia completo |
| Gerar uma câmera | `/camera-obscura give camera` | Em geral é um comando administrativo |
| Configuração do VeinMiner | `/veinminer settings` | Voltado a administradores |
| Configurar Vanilla Refresh | `/function vanilla_refresh:_settings` | Alterações dependem de acesso administrativo |

## Teletransporte com TPA

1. Digite `/trigger TPA`.
2. Selecione no chat o jogador ao qual deseja ir.
3. Aguarde a confirmação do destinatário.
4. Se não houver aceitação no prazo previsto pelo mod, a solicitação expira.

**Atenção:** este pacote inclui um arquivo TPA nomeado para `26.2`, embora o Minecraft do manifesto seja `26.3`. Se o comando não funcionar, a administração deve testar a compatibilidade da versão instalada.

## Sem comandos: ações rápidas

- **Baús classificadores:** coloque um baú sobre bloco de esmeralda ou diamante. [Guia de armazenamento](/docs/explicacao-mods/armazenamento).
- **Molduras invisíveis:** agache e clique com botão direito sobre a moldura. [Guia de construção](/docs/explicacao-mods/construcao).
- **Engarrafar XP:** agache e clique com o botão direito segurando garrafa de vidro vazia. [Guia de sobrevivência](/docs/explicacao-mods/sobrevivencia).
- **Sino na pesca:** segure um sino na mão secundária para ouvir quando o peixe fisgar.

Consulte também o [Image2Map](/docs/explicacao-mods/image2map) e o [Camera Obscura](/docs/explicacao-mods/cameraobscura) para detalhes sobre comandos de imagens.
